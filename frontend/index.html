Configure your voice agent

Add these private values to your Render service’s Environment tab. They stay on Render and are never exposed in this website.

TWILIO_ACCOUNT_SIDTwilio Account SID (starts with AC)
TWILIO_AUTH_TOKENTwilio Auth Token
TWILIO_PHONE_NUMBERYour Twilio phone number
MY_PHONE_NUMBERThe verified number to call
ELEVENLABS_AGENT_IDElevenLabs Conversational AI agent ID
ELEVENLABS_API_KEYElevenLabs API key
FRONTEND_URLThis Vercel site URL after deployment
